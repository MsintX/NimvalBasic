EzWindow layout and password-mask update (2026-10-31):
- `loction(distance, top, bottom, left, right)` accepts `%` or `px` as the shared distance unit.
- `size(px, length, width)` sets explicit pixel dimensions; first value is horizontal width, second is vertical height.
- Without `size`, the remaining space between opposing edges determines the control size.
- Explicit zero/negative-after-rounding dimensions and fully consumed percentage dimensions are rejected with NB-EZ1002.
- Win32 EDIT password controls explicitly use `*` via EM_SETPASSWORDCHAR.
- GTK PasswordEntry uses `*` as its invisible character.
- Added regression coverage for percent/pixel locations, explicit dimensions and zero-size rejection.
