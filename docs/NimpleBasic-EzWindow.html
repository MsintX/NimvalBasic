Nimval Basic with EasyWindow

使用 Nimval Basic 编写桌面窗口、按钮、文本输入、密码框、下拉框、单选按钮、滑块、进度条；Windows 可选嵌入 WebView2。EasyWindow 提供统一 API，并调用各平台的原生 GUI 后端。

第一个窗口

EasyWindow 程序使用无参数的 void Window 作为入口；窗口标题默认是 EasyWindow Application，默认大小为 200×200，也可以显式指定标题和尺寸。保存为 HelloWindow.nb。include 必须位于程序语句之前。

include 

var new root = window("我的第一个 Nimval Basic 窗口", 520, 320)
var new greeting = label(root, "你好，Nimval Basic！")
var new nameInput = entry(root, "请输入姓名")
var new greetButton = button(root, "打招呼")

void greet:
    setText(greeting, "你好，" + getText(nameInput) + "！")
    return
end

void Window:
    pack(greeting)
    pack(nameInput)
    pack(greetButton)
    onClick(greetButton, "greet")
    mainloop()
    return
end

运行：

nimple-basic HelloWindow.nb
Window 必须无参数且返回 void；不需要再定义 Main。控件创建时会自动加入窗口默认布局；pack(widget) 保留为兼容接口，不改变布局。需要指定位置和尺寸时使用 setBounds 或 setRelativeBounds；用 onClick 注册按钮回调，最后调用 mainloop() 进入 GUI 事件循环。

EasyWindow 的工作方式

  • Nimval Basic 层：include 从解释器同级的 Standard library/EasyWindow 导入 Nimval Basic API 声明。
  • 原生后端：调用 Windows、macOS 或 Linux 对应 GUI 接口创建真实桌面控件。
  • 事件驱动：用户点击按钮、修改输入框或切换复选框时，EasyWindow 调用已注册的 Nimval Basic 方法。

标准库模块（包括 EasyWindow API 声明和 Math）以无扩展名文件放在解释器同级的 Standard library 文件夹中。运行时根据解释器自身路径定位，不受当前工作目录影响。

位置、尺寸与自动相对布局

EasyWindow 现在提供固定像素布局和响应式百分比布局。坐标原点是窗口客户区左上角，不是整个屏幕左上角。控件在创建时默认按创建顺序纵向排列；调用以下布局 API 后，该控件切换为自定义布局。

1. 固定像素位置：setPosition

setPosition(widgetId, x, y) 设置控件左上角相对于窗口客户区的像素坐标。该控件切换为固定像素布局，窗口大小变化时位置不会按比例重新计算。

include 

var new root = window("Position example", 640, 400)
var new status = label(root, "Positioned at x=24, y=20")

setPosition(status, 24, 20)

void Window:
    mainloop()
    return
end

2. 固定像素尺寸：setSize

setSize(widgetId, width, height) 设置控件宽度和高度，单位为像素。宽和高必须大于 0。该方法同样将控件切换到固定像素布局，并保留当前的位置。

include 

var new root = window("Size example", 640, 400)
var new action = button(root, "Submit")

setSize(action, 160, 40)

void Window:
    mainloop()
    return
end

3. 一次指定位置与尺寸：setBounds

setBounds(widgetId, x, y, width, height) 是 setPosition 和 setSize 的组合，用于一次设置控件的完整像素矩形。

include 

var new root = window("Bounds example", 640, 400)
var new action = button(root, "Run")

setBounds(action, 28, 24, 180, 42)

void Window:
    mainloop()
    return
end

4. 自动相对定位：setRelativeBounds

setRelativeBounds(widgetId, xPercent, yPercent, widthPercent, heightPercent) 使用窗口客户区的百分比来确定控件位置和大小。窗口调整尺寸时，EasyWindow 会重新计算该控件的像素矩形。

参数含义示例
xPercent左侧位置占客户区宽度的百分比5 表示从左侧 5% 开始
yPercent顶部位置占客户区高度的百分比20 表示从顶部 20% 开始
widthPercent控件宽度占客户区宽度的百分比60 表示占 60% 宽度
heightPercent控件高度占客户区高度的百分比10 表示占 10% 高度

每个百分比参数都是 0 到 100 的整数。宽、高百分比必须大于 0，并且位置加尺寸不能超出客户区：xPercent + widthPercent <= 100，yPercent + heightPercent <= 100。

include 

var new root = window("Responsive layout", 900, 600)
var new title = label(root, "Responsive interface")
var new nameInput = entry(root, "Your name")
var new submit = button(root, "Submit")
var new notes = textBox(root, "The text area grows with the window.")

setRelativeBounds(title, 5, 5, 90, 8)
setRelativeBounds(nameInput, 5, 18, 65, 10)
setRelativeBounds(submit, 73, 18, 22, 10)
setRelativeBounds(notes, 5, 34, 90, 50)

void Window:
    mainloop()
    return
end

5. 四种布局 API 的差异

方法单位窗口缩放时适用场景
setPosition像素位置不按比例变化固定位置控件
setSize像素尺寸不按比例变化固定大小按钮或输入框
setBounds像素矩形不按比例变化明确像素布局
setRelativeBounds百分比位置和尺寸都自动重算响应式窗口界面
控制尺寸时，平台原生控件可能有自己的最小自然尺寸；不同系统的字体度量、边框和系统主题也可能造成少量差异。相对百分比依据窗口客户区计算，不包括标题栏和窗口边框。

6. 混合使用

同一窗口中的控件可以混用固定像素与相对布局。调用 setRelativeBounds 会切换为相对布局；随后调用 setPosition、setSize 或 setBounds 则重新切换为固定像素布局。默认自动纵向布局只会继续管理尚未自定义布局的控件。

事件与回调

按钮点击

回调名称以字符串传入，目标必须是已声明的 Nimval Basic 方法。点击事件回调不接收参数。

void save:
    messageBox("Saved", "Your changes were saved.")
    return
end

void Window:
    var new saveButton = button(root, "Save")
    pack(saveButton)
    onClick(saveButton, "save")
    mainloop()
    return
end

输入变化

onChange 支持单行输入框、多行文本框、密码输入框、复选框、单选按钮、下拉框和滑块。回调需要一个参数，变化值统一以字符串传入；滑块变化值为整数的十进制文本。

void inputChanged with currentText as string:
    setText(statusLabel, "输入：" + currentText)
    return
end

void Window:
    onChange(nameInput, "inputChanged")
    mainloop()
    return
end
回调方法必须在静态检查可见的范围内声明。绑定时使用方法名字符串，例如 onClick(buttonId, "greet")，不要写成 onClick(buttonId, greet)。

完整示例：问候应用

include 

/* Root widgets are globals so event methods can access them. */
var new root = window("Nimval Basic + EasyWindow", 520, 340)
var new greeting = label(root, "请输入姓名，然后点击按钮。")
var new nameInput = entry(root, "你的姓名")
var new greetButton = button(root, "打招呼")
var new notes = textBox(root, "EasyWindow 使用系统原生控件。")
var new friendly = checkBox(root, "启用友好模式")

void greet:
    if getText(nameInput) == "" then
        setText(greeting, "请先输入姓名。")
    else
        if getChecked(friendly) then
            setText(greeting, "你好，" + getText(nameInput) + "！祝你今天愉快。")
        else
            setText(greeting, "你好，" + getText(nameInput) + "！")
        end
    end
    return
end

void Window:
    pack(greeting)
    pack(nameInput)
    pack(greetButton)
    pack(notes)
    pack(friendly)
    onClick(greetButton, "greet")
    mainloop()
    return
end

建议将完整示例与项目中的 examples/EasyWindowHello.nb 对照使用。

运行与构建

先检查，再运行

nimple-basic --check HelloWindow.nb
nimple-basic HelloWindow.nb

构建解释器

cmake -S . -B build
cmake --build build --config Release

Windows 用户也可以在 Visual Studio 中打开 NimpleBasic.sln 并构建。请确保运行的是刚刚重新编译的 nimple-basic.exe；仅更新源码不会改变旧 EXE 的行为。

启用可选的 WebView2（Windows）

安装 Microsoft WebView2 SDK，将 WEBVIEW2_SDK_DIR 指向 SDK 包的 build/native 目录，再运行：

cmake -S . -B build -DNIMPLE_ENABLE_WEBVIEW2=ON -DWEBVIEW2_SDK_DIR="C:/path/to/Microsoft.Web.WebView2/build/native"
cmake --build build --config Release

Visual Studio 项目可将 WebView2SDKDir 属性设置到同一目录。目标用户还必须安装 WebView2 Runtime。

平台与原生后端

平台后端方式依赖与说明
WindowsWin32 原生控件；可选 WebView2通用控件无需第三方 GUI 框架；WebView2 需单独安装 SDK 并启用编译开关，运行时需安装 WebView2 Runtime。Windows 8.1 不受 WebView2 Runtime 支持。
macOSCocoa / AppKit使用系统提供的窗口和控件；需在 macOS 上使用 Apple Clang 构建与验证。
Linux运行时动态加载 GTK 3无需 GTK 头文件或链接期开发依赖；运行 GUI 程序的桌面系统需要 GTK 3 运行库与可用的图形会话。
Linux 没有统一的操作系统级原生按钮/文本框 API，因此当前 Linux 后端使用桌面环境常见的 GTK 3 运行库。通用控件在各平台映射到平台原生控件；WebView2 仅在 Windows 且显式启用时可用。Windows 8.1 不支持 WebView2 Runtime。各目标系统仍应进行实际 GUI 冒烟测试。

常见问题

报错“EasyWindow 当前未启用”

通常表示运行的 EXE 没有包含对应的 GUI 后端，或正在使用旧构建产物。用当前工程重新构建，再运行新生成的 nimple-basic.exe。

窗口或控件没有出现

  • 确认控件创建函数返回成功，并且最后调用了 mainloop()。
  • 确认最后进入了 mainloop()。
  • 确认运行环境有可用桌面会话；Linux 还需 GTK 3 运行库。
  • 先运行 nimple-basic --check HelloWindow.nb 排除语法和类型错误。

点击按钮没有反应

检查 onClick 中的回调名是否与方法声明完全一致；点击回调应为无参数的 void 方法。
